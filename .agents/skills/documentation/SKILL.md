# Documentation

Use the contributor-facing policies in
[`docs/source/development/contributing.md`](../../../docs/source/development/contributing.md)
as the source of truth for project conventions.

## Select the scope

Read only the references needed for the task:

- Python docstrings: [docstrings.md](references/docstrings.md)
- Sphinx source pages: [source-docs.md](references/source-docs.md)
- Root documentation: [root-docs.md](references/root-docs.md)
- Inline comments: [inline-comments.md](references/inline-comments.md)
- Rendered HTML: [visual-docs.md](references/visual-docs.md)
- Domain terms: [terminology.md](references/terminology.md)

For an audit, also read [auditing.md](references/auditing.md) and the canonical
[check-code registry](references/check-codes.md). Apply one shared procedure across all
selected scopes.

For an edit, apply the relevant conventions directly. Preserve established terminology
and validate the smallest useful documentation surface.
